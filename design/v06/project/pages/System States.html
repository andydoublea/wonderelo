Notes for implementation

  • All seven states use only --w-* tokens; the two extra colors — --ss-error #c0392b and --ss-ok #1f8a4d — are the only additions. Promote them to --destructive / --success in globals.css.
  • Loading: reuse the <Skeleton /> card shape per list; the inline spinner is for buttons and small async regions.
  • Empty / Error / Offline / 404: one shared <StatePlaceholder glyph title body actions /> component covers all four — only glyph, copy and buttons change.
  • Form: field-level hint (.ss-hint) + a form-level banner (.ss-banner) + a success view. Wire to the existing validation state; no new endpoints.
